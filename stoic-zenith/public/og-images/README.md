# Open Graph Images

This directory contains dedicated Open Graph images for each page type.

## Required Images

The following OG images need to be created (1200x630px):

- `quotes.png` - For the quotes page
- `journal.png` - For the journal page
- `mentors.png` - For the mentors page
- `calendar.png` - For the calendar/memento mori page
- `settings.png` - For the settings page
- `home.png` - For the home page (if needed)

## Design Guidelines

- Size: 1200x630 pixels
- Format: PNG or JPG
- Include app branding/logo
- Use consistent visual style with the app
- Include page-specific imagery or iconography
- Keep text readable and minimal
- Ensure images look good when shared on social media
