# The Stoic Way - SEO Guidelines & Best Practices

## Core SEO Page Rules

### Title Tag Requirements

**Character Limits & Structure:**

- Keep titles between 50-60 characters (optimal for SERP display)
- Include primary keyword near the beginning (first 5-10 words)
- Make each title unique and descriptive across all pages
- Use compelling language that encourages clicks
- Include brand name at the end when appropriate: "| The Stoic Way"

**Examples:**

```
✅ Good: "Marcus Aurelius: Roman Emperor & Stoic Philosopher | The Stoic Way"
✅ Good: "Daily Stoic Practices for Modern Living | The Stoic Way"
❌ Bad: "Marcus Aurelius - Learn About This Amazing Roman Emperor and Stoic Philosopher Who Changed History"
❌ Bad: "Page 1 | The Stoic Way"
```

### Meta Description Guidelines

**Character Limits & Content:**

- Write descriptions between 150-160 characters (optimal for SERP display)
- Include primary and secondary keywords naturally
- Create unique descriptions for each page
- Write compelling copy that summarizes page content
- Include a clear call-to-action when relevant

**Structure Formula:**
`[Hook/Value Proposition] + [Key Information] + [Call-to-Action]`

**Examples:**

```
✅ Good: "Explore Marcus Aurelius, the Roman Emperor and Stoic philosopher. Discover his 'Meditations', key quotes, and influence on Western thought."
✅ Good: "Master daily Stoic practices with our comprehensive guide. Learn meditation, journaling, and virtue exercises from ancient wisdom."
❌ Bad: "This page is about Marcus Aurelius and stuff."
❌ Bad: "Learn about Stoicism and philosophy and ancient wisdom and how to apply it to your modern life and become better."
```

## URL Structure & Slug Rules

### Technical Requirements

- **Case:** Use lowercase letters only
- **Separators:** Use hyphens (-) to separate words, never underscores (\_)
- **Length:** Keep under 60 characters (3-5 words maximum)
- **Characters:** Remove special characters, apostrophes, quotes, and stop words
- **Consistency:** Maintain consistent patterns across similar content types

### Keyword Optimization

- Include primary keyword early in the slug
- Avoid keyword repetition within the same URL
- Match slug to page title/H1 when natural
- Use semantic, descriptive words that indicate content

### URL Examples

```
✅ Good Examples:
/events/diadochi-wars-322-275-bce
/blog/marcus-aurelius-meditations-guide
/quotes/seneca-wisdom-collection
/mentors/epictetus-teachings

❌ Bad Examples:
/page?id=12345
/the-ultimate-complete-guide-to-stoic-philosophy-for-beginners
/SEO_Tips_&_Tricks!!!
/Marcus_Aurelius's_Best_Quotes
```

### Redirect Rules

- Set up 301 redirects when changing existing slugs
- Never break existing URLs without proper redirects
- Monitor and fix broken internal links regularly

## Content Requirements

### Word Count Standards

- **Standard Pages:** Minimum 300 words
- **Blog Posts:** Minimum 1,000 words
- **Event Pages:** Minimum 800 words
- **Philosopher Biographies:** Minimum 1,200 words

### Keyword Integration

- Include primary keyword in the first 100 words
- Use keyword variations and related terms naturally (LSI keywords)
- Maintain keyword density between 1-2% (avoid keyword stuffing)
- Focus on semantic relevance over exact match repetition

### Content Structure Requirements

- Answer user intent comprehensively
- Use clear, logical flow with proper transitions
- Include relevant examples and practical applications
- Provide actionable insights and takeaways
- Cite authoritative sources when making claims

## On-Page Elements

### Header Tag Hierarchy

```
H1: Primary page title (only one per page)
├── H2: Main section headings (2-4 per page)
│   ├── H3: Subsection headings
│   └── H3: Subsection headings
├── H2: Main section headings
│   ├── H3: Subsection headings
│   └── H3: Subsection headings
```

**Header Tag Rules:**

- Use only one H1 tag per page containing the primary keyword
- Include keywords in 2-3 H2 subheadings naturally
- Maintain logical hierarchy (don't skip from H1 to H3)
- Keep headers descriptive and scannable

### Image Optimization

- Add alt text to all images with descriptive, keyword-rich text
- Use descriptive file names: `marcus-aurelius-statue.jpg` not `IMG_001.jpg`
- Optimize file sizes for fast loading (WebP format preferred)
- Include captions when they add value

### Internal Linking Strategy

- Include 3-5 internal links per page to related content
- Use descriptive anchor text (avoid "click here" or "read more")
- Link to both newer and older relevant content
- Create topic clusters linking related pages

### External Linking

- Include 1-2 external links to authoritative sources
- Link to reputable sites (.edu, .gov, established publications)
- Use rel="noopener" for security on external links
- Ensure external links add value to the content

## Technical SEO Requirements

### Page Speed Optimization

- Target Core Web Vitals scores:
  - LCP (Largest Contentful Paint): < 2.5 seconds
  - FID (First Input Delay): < 100 milliseconds
  - CLS (Cumulative Layout Shift): < 0.1

### Mobile Optimization

- Ensure responsive design across all devices
- Test on multiple screen sizes and orientations
- Optimize touch targets (minimum 44px)
- Ensure readable font sizes without zooming

### Structured Data (Schema Markup)

- Implement Article schema for blog posts
- Use Person schema for philosopher biographies
- Add HistoricalEvent schema for event pages
- Include Organization schema for brand information

**Example Schema for Events:**

```json
{
  "@context": "https://schema.org",
  "@type": "HistoricalEvent",
  "name": "The Diadochi Wars",
  "startDate": "322 BCE",
  "endDate": "275 BCE",
  "location": "Mediterranean Basin",
  "description": "Series of conflicts between Alexander's successors"
}
```

## Content-Specific SEO Guidelines

### Blog Posts

- Include publication date and author information
- Use categories and tags strategically
- Add social sharing buttons
- Include related posts section
- Implement breadcrumb navigation

### Event Pages

- Include historical dates and locations
- Add timeline elements when relevant
- Link to related historical figures
- Include primary sources when available
- Use period-appropriate imagery

### Philosopher Biographies

- Include birth/death dates and locations
- Add quotes and key teachings
- Link to related philosophical concepts
- Include historical context
- Add recommended reading sections

## Monitoring & Maintenance

### Regular SEO Audits

- Check for broken links monthly
- Monitor page speed quarterly
- Review and update meta descriptions annually
- Audit keyword rankings monthly
- Check mobile usability regularly

### Analytics Tracking

- Set up Google Analytics 4
- Monitor Core Web Vitals in Search Console
- Track keyword rankings
- Monitor click-through rates from SERPs
- Analyze user behavior and engagement metrics

### Content Updates

- Refresh content annually or when information changes
- Update publication dates for significant revisions
- Add new internal links to fresh content
- Remove or update outdated information
- Expand thin content to meet minimum word counts
