Core SEO Page Rules
Title Tag Requirements

Keep titles between 50-60 characters
Include primary keyword near the beginning
Make each title unique and descriptive
Use compelling language that encourages clicks
Include brand name at the end when appropriate
Meta Description Guidelines

Write descriptions between 150-160 characters
Include primary and secondary keywords naturally
Create unique descriptions for each page
Write compelling copy that summarizes page content
Include a clear call-to-action when relevant
URL Structure

URL Slug Rules
Structure: Use lowercase letters only, separate words with hyphens (-), remove special characters and stop words, keep under 60 characters (3-5 words max).
Keywords: Include primary keyword early in the slug, avoid repetition, match slug to page title/H1 when natural.
Technical: Never use spaces or underscores, remove apostrophes/quotes, set up 301 redirects if changing existing slugs, maintain consistent patterns across similar content.
Use lowercase letters only
Content Requirements
Good: /seo-optimization-guide
Good: /best-running-shoes-2025
Bad: /page?id=12345
Bad: /the-ultimate-guide-to-seo-optimization-for-websites
Bad: /SEO*Tips*&\_Tricks!!!

Write at least 300 words for standard pages, 1000+ for blog posts
Include primary keyword in the first 100 words
Use keyword variations and related terms naturally
Structure content with clear headings (H1, H2, H3)
Answer user intent comprehensively
On-Page Elements

Use only one H1 tag per page containing the primary keyword
Include keywords in 2-3 H2 subheadings
Add alt text to all images with descriptive, keyword-rich text
Use internal links to related content (3-5 per page)
Include external links to authoritative sources
